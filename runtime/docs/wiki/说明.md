## 项目一句话简介

**distributed-runtime** 是一套"可编排、可迁移、可扩展、可恢复"的分布式应用基础运行时：Node 是资源容器、Capability 是可启停的能力（MOCK/CACHE/STORAGE）、Partition 是逻辑数据单元、Placement 是所有权映射、Epoch 是所有权版本（Fencing Token）、Migration 是所有权转移、Scheduler 是 Desired→Actual 收敛器。支持单节点独立运行与多节点自动组集群。

## 快速上手（TL;DR）

```powershell
# 1. 构建
.\mvnw.cmd -f runtime -DskipTests install

# 2. 单节点（进程内存储，无需 PG）
$env:RUNTIME_STORE='memory'; $env:RUNTIME_NODE_GRPC_PORT='0'; $env:SERVER_PORT='0'
java -jar runtime\server\target\runtime-server-1.0-SNAPSHOT.jar
```

```bash
# 3. Docker 四节点集群（需宿主机 PostgreSQL，见 runtime/docker-compose.yml）
./runtime/deploy-runtime.sh all      # 构建 jar + 前端 + 镜像 + 起集群
./runtime/scale-out.sh 5             # 动态扩第 5 个节点
```

详细内容见 [12-快速开始.md](12-快速开始.md)。

## 术语表

| 术语 | 含义 |
|---|---|
| Node | 物理计算资源容器（≠角色），每节点含 gRPC 端口与资源快照 |
| Capability | 可运行能力（MOCK/CACHE/STORAGE，预留 API/TASK），可在任意 Node 启停；数据面实现在 runtime-data |
| Partition | 逻辑数据单元，默认 4096 个/能力命名空间，编号 `P000001..P004096` |
| Placement | 分区所有权映射（显式表 `rt_partition_placement`，非计算式路由；每分区 1 行 PRIMARY + N−1 行 REPLICA） |
| Epoch | 所有权版本 / Fencing Token：切主 +1，旧 epoch 写入被拒绝 |
| Migration | 所有权转移：状态机驱动 + gRPC 分片传输 + 断点续跑 |
| Scheduler | Desired→Actual 收敛器：PG 租约竞选 Leader，无固定 Master |
| Desired / Actual | 期望态（管理面写入）/ 实际态（节点状态机产出），二者之差由 ReconcileLoop 收敛 |
| Reconcile | 调谐：对比 desired/actual → 生成命令与迁移计划 → 幂等执行 |
| Cutover | 切主：`PlacementStore.cutover` 以 epoch CAS 语义原子换主；目标已持副本时走 `promoteReplica` 无损提升 |
| Fencing | 拒绝陈旧 Owner 写入：`StaleEpochException` |
| Leader Lease | `rt_scheduler_lease` 单行表乐观锁租约，全集群至多一个 Leader |
| Decommission | 节点退役：`rt_decommission` 记录驱动，DRAINING→REMOVING→COMPLETED/FAILED，由 Leader 每周期 `DecommissionDriver.advance()` 推进 |
