# Runtime UI

Runtime管理前端，基于 **Vue 3 + AdminLTE v4 (Bootstrap 5)** 构建，内嵌到Spring Boot jar中。
每个节点独立提供服务，访问任意节点即可打开管理界面。

## 技术栈

- Vue 3 (Composition API) + TypeScript
- naive-ui 组件库 + Tailwind CSS v4（工具类布局）
- Vue Router (hash模式)

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式（代理到localhost:8091）
pnpm dev

# 构建（产物输出到../server/src/main/resources/static/）
pnpm build
```

## 构建后

前端构建产物会自动输出到 `runtime/server/src/main/resources/static/`，执行 `mvn package` 时会打包进Spring Boot jar。

启动runtime后访问：
- 节点1: http://localhost:8091/
- 节点2: http://localhost:8092/
- 节点3: http://localhost:8093/
- 节点4: http://localhost:8094/

## 功能

- **集群管理**（默认首页，已合并原集群概览）：集群节点/存活节点/角色/Leader/Lease/活跃迁移统计卡片、节点列表（含退役操作）、能力列表（含期望/实际 ACTIVE 汇总）、缓存/存储调度面板、分区路由查询
- **能力管理**：表格化展示各节点CACHE/STORAGE能力，支持一键启用/禁用
- **分区路由查询**：按key查询分区号、属主节点、Epoch等fencing信息
- **节点详情**：单节点详细信息、能力状态、调谐状态
- **侧边栏动态菜单**：自动显示所有节点，Leader节点带特殊标记

## 扩展业务后台

未来新增业务页面只需：
1. 在 `src/views/` 下添加页面组件
2. 在 `src/main.ts` 的 `routes` 中注册路由，添加 `meta.title` 和 `meta.icon`
3. 即可自动出现在左侧菜单中（或通过App.vue的menuItems扩展）
